# サンプルサイト2号 — 株式会社タカミネ精工（架空の中小製造業コーポレートサイト）

Web制作の受注用ポートフォリオとして制作した、架空の精密部品加工メーカーのコーポレートサイトです。
サンプル1号（カフェ・1ページ構成）とは対照的に、**複数ページ構成で共通パーツを使い回す作り**を見せることを目的にしています。下層ページのボディ実装など、コーディング案件への応募を想定しています。

## 概要
- ジャンル：B2B製造業（精密部品加工）コーポレートサイト
- デザイン：ネイビー×グレーを基調にした、信頼感のあるB2B向けデザイン

## ページ構成（全5ページ＋共通ファイル）
| ファイル | 内容 |
|---|---|
| index.html | トップ：ヒーロー／事業紹介サマリー（カード3枚）／強み3点／お知らせ最新3件／会社概要サマリー／CTA |
| business.html | 事業内容：精密加工・試作開発・品質管理の3事業（画像付き交互レイアウト）／主要設備の表（8機種） |

| news.html | お知らせ一覧：日付＋カテゴリタグ（お知らせ／製品／展示会／採用）＋タイトル、全8件 |
| contact.html | お問い合わせ：会社情報サイドバー＋フォーム（デモ動作：未入力チェック＋完了表示） |
| style.css | 全ページ共通スタイルシート |
| script.js | 全ページ共通スクリプト |
| assets/ | AI生成画像4枚（webp） |

## 共通パーツの設計
- ヘッダー（固定表示・ロゴ＋グローバルナビ）／フッター（サイトマップ＋サンプル明記）は全ページ同一マークアップで使い回し
- ナビは現在ページをハイライト（`.is-current` ＋ `aria-current="page"` をページごとに付け替え）
- 下層ページにはパンくずリストとページヒーロー（帯タイトル）を共通配置

## 技術・工夫点
- HTML / CSS / JavaScript（フレームワークなし）、CSS変数でカラーパレットと余白を一元管理
- レスポンシブ対応：ブレークポイント2段階（900px／720px）。スマホはハンバーガーメニュー、カードは3列→2列→1列に段組み変更
- スクロール連動のフェードイン（IntersectionObserver、控えめな動き。`prefers-reduced-motion` にも配慮）
- お問い合わせフォームはJavaScriptで未入力・形式チェックを行い、エラー表示→完了表示まで動作（実際の送信はしません）
- セマンティックなマークアップ、代替テキスト、フォーカス表示などアクセシビリティに配慮
- 画像：AI生成画像（工場外観・加工現場・CNC工作機械・精密部品）を使用。実案件では企業提供写真またはフリー素材に差し替え可能
